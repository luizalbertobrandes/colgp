Modelagem de Cargos

Para Chiavenato, o cargo é a unidade básica da organização. Esta aplicação explora como mapear o que o cargo é (Descrição) e o que ele exige (Análise), fornecendo as ferramentas para uma gestão estratégica de talentos.

1. Descrição vs. Análise de Cargos

Embora complementares, possuem focos distintos: um olha para dentro do cargo (conteúdo), o outro para fora (requisitos do ocupante).

Descrição de Cargos

Mapeamento narrativo das tarefas e deveres. É impessoal e foca no cargo.

  • ✔ O que o cargo faz?
  • ✔ Quando faz?
  • ✔ Como faz?
  • ✔ Por que faz?

Análise de Cargos

Investigação dos requisitos extrínsecos e exigências impostas ao ocupante.

  • ✔ Requisitos Mentais
  • ✔ Requisitos Físicos
  • ✔ Responsabilidades
  • ✔ Condições de Trabalho

2. Fatores de Análise de Cargos

A análise subdivide-se em quatro grandes áreas que determinam o perfil do ocupante. Veja abaixo a distribuição típica de exigências em diferentes níveis de cargo.

A
Requisitos Mentais

Instrução, experiência, aptidões e adaptação.

B
Requisitos Físicos

Esforço físico, concentração visual e constituição.

C
Responsabilidades Assumidas

Supervisão, materiais, valores e contatos.

D
Condições de Trabalho

Ambiente físico e riscos ocupacionais.

4. O Valor Estratégico (Aplicações)

A descrição e análise não são fins em si mesmas, mas o combustível para toda a Gestão de Pessoas.

👤
Recrutamento e Seleção

Define o perfil ideal do candidato com base nos requisitos e competências esperadas.

🎓
Treinamento (T&D)

Identifica lacunas (gaps) entre o que o cargo exige e o que o ocupante domina.

📊
Avaliação de Desempenho

Estabelece critérios objetivos para medir se o trabalho atinge as metas propostas.

💰
Administração Salarial

Base para a avaliação de cargos e estruturação de faixas salariais equitativas.

🛡
Higiene e Segurança

Mapeia riscos ambientais, ergonômicos e necessidades de proteção.

"A descrição foca no cargo, a análise foca no perfil."
